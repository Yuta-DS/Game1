## What “included like `./setup.sh run`” means here

The final local Web export starts, accepts Offline Guest, moves the player, mounts the gallery and World One, loads the checked dynamic resources, and passes the chat-specific browser audits above. This proves those requested scenes and mechanics are present and playable at the tested paths. It does **not** prove that every desktop feature has an equivalent browser implementation: the desktop launch uses Godot Mono and native C# plus a local model, while the Web export uses non-Mono Godot and substitutes browser-compatible paths. Whole-route keyboard traversal and those broader feature differences remain outside this screenshot check.
