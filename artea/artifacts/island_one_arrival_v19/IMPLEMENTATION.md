# Island One — World Gate Landing v19

Island One is now treated as a complete arrival station rather than an open deck with a rectangular portal. The new landmark follows the supplied map reference: a symmetrical ivory-and-brass conservatory with a teal faceted roof, two domed navigation towers, a curved World Gate facade, formal garden planters and a clear bridge-to-gate procession.

## Reusable component breakdown

- `CelestialWorldGateArrival` — root assembly with style, purpose, revision and route-clearance metadata.
- `TriangulatedAetherConservatory` — seven paired structural ribs, ten columns and 144 independently editable triangular glass panels.
- `WorldGateCelestialArch` — curved segmented portal facade around the existing functional return gate.
- `WestAetherLanternTower` / `EastAetherLanternTower` — mirrored beacon and levitation-pressure towers assembled from plinth, drum, compression bands, enamel vanes, glass dome, finial and beacon pearl.
- Four `ArrivalGarden` modules — ivory basin, brass lip, soil insert and individual heavenly blooms.
- Processional court — ivory floor shell, outer brass ring, inner aether ring and a central gilt route inlay.

The standalone and authored-galaxy versions use the full assembly. The compact in-castle Mind district reuses the same assembly at 32% scale, so Island One keeps one visual identity in every playable mode. The existing bridge, return gate, story checkpoint and player route are retained.
