## Layout system

- Page size: 8.5 × 11 inches, portrait.
- Margins: left/right 1.0 inch; top/bottom 0.75 inch.
- Header/footer distance: 0.35 inch.
- Header: `ARTÉA / WORLD DESIGN BIBLE`, left aligned, muted Calibri 8.5 pt.
- Footer: world title plus automatic page number, right aligned, muted Calibri 8.5 pt.
- Content width: 6.5 inches. Tables use fixed column widths and repeat header rows.
- Major parts start on a new page. Heading hierarchy and content order are preserved.
