# Milo scripture corpus source

- Translation: World English Bible, Protestant edition (WEBP)
- Canon: 66-book Protestant canon
- Official source: <https://ebible.org/engwebp/>
- Developer archive: <https://ebible.org/Scriptures/engwebp_vpl.zip>
- Rights: public domain; the generated files preserve the source wording
- Build tool: `tools/build_milo_scripture_index.py`

The corpus is generated at build time and read locally at runtime. Player chat
is not sent to this source or to any other remote service.
